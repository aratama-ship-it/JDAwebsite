# AJDCサイト更新レビュー・デバッグ記録

- 整理日: 2026-08-22
- 対象: `external/AJDC/index.html`
- 比較元: 現行公開AJDCサイト、Git `HEAD` の旧WordPressミラー、現在の静的リデザイン案
- 方針: 既存の大会情報・更新情報を失わず、WordPress依存を段階的に外す

## 結論

現在の静的トップ案は、表示崩れと基本的なアクセシビリティ上の問題を修正すれば、デザイン確認用モックとして使用できる。ただし、そのまま現行AJDCサイト全体と入れ替えることはできない。現行サイトが持つ大会情報、選手登録、専用お問い合わせ、2012年以降の結果アーカイブ、PDF・画像資産がまだWordPress側に残っているためである。

公開前の最重要課題は、完成キービジュアルの承認、既存コンテンツとURLの移行、WordPress配下の資料保全、公開・復旧手順の確定である。

## 今回修正した不具合

- 320〜620pxでセクション見出しがデスクトップ用2列グリッドに戻り、ページ全体が横にはみ出すCSSカスケード不具合を修正。
- スマートフォンで「全日本ディアボロ」の末尾だけが孤立改行する見出しサイズを修正。
- スマートフォンのナビ5項目が初期表示内に収まるよう、間隔と字間を調整。
- 小さいナビ・ラベル・ボタン、結果カード、問い合わせカードの文字コントラストを改善。
- モバイルナビのリンク領域を高さ44pxへ拡張し、ティール背景上の白ボタンには白いフォーカス輪を設定。
- キーボード用スキップリンク、`:focus-visible`、`prefers-reduced-motion`対応を追加。
- 読み上げで意味のない「15」「AJDC」として現れていた装飾文字を削除。
- 英語UIの主要箇所へ`lang="en"`を追加し、日本語のナビゲーション名・大会概要ラベルを設定。
- Google Fonts URLの未エスケープ`&`を修正し、canonical、暫定favicon、Apple Touch Iconを追加。
- 読み込んでいない`Public Sans`指定を外し、実際に利用可能なシステムフォント構成へ整理。
- 大屋養蜂園のリンクをHTTPから到達確認済みのHTTPSへ変更。
- 本番配置時に404になる相対お問い合わせリンクを、現行AJDC専用お問い合わせURLへ暫定修正。
- 旧トップにあった暫定スケジュール、選手登録開始、開催告知、AJDC2025結果の更新履歴を復元。
- 大会情報、誓約書、採点規則、歴代結果、選手登録への暫定導線を資料欄へ復元。

## 公開前ブロッカー（P0）

### 1. キービジュアルを完成版へ差し替える

現在の`external/AJDC/images/ajdc-hero-placeholder.png`は仮画像で、Git上も未追跡である。HTMLだけ公開すると画像が欠落する。

- 使用する選手写真と人物ごとの利用許諾を確認する。
- 合成後の構図、選手名の扱い、大会ロゴ・文字の重なりを関係者が承認する。
- デスクトップとスマートフォンのトリミングを別々に確認する。
- 完成画像をWebPまたはAVIFへ最適化し、必要なら画面幅別画像を用意する。
- ファイルをGit管理し、同名差し替え時は画像URLのキャッシュ番号を更新する。
- OGP画像としても使うかを決める。

### 2. 現行4ルートを静的ページへ移行する

WordPressは最終的に廃止する方針で確定した。現行AJDCにはトップ以外に次の公開ルートがあるため、内容を静的ページへ移し、現在と同じ公開URLを維持する。静的トップ案は、移行完了までこれらの現行URLへつなぐ暫定構成である。

- `/AJDC/about/`: 大会目的、誓約書、採点規則、観覧・三脚条件、会場アクセス
- `/AJDC/registration/`: 個人・団体登録、提出物、Tシャツ案内
- `/AJDC/contact/`: AJDC専用お問い合わせフォーム
- `/AJDC/result/`: 2012〜2026年の開催要項・結果アーカイブ

移行作業では、各ページの本文・資料・フォーム要件を静的版へ引き継ぎ、`/AJDC/about/`、`/AJDC/registration/`、`/AJDC/contact/`、`/AJDC/result/`を同じURLで公開する。構成上どうしてもURLを変更する箇所だけ、旧URLから恒久リダイレクトする。

### 3. WordPress資産を恒久パスへ移す

現在の静的トップは次の資料を`/AJDC/wp-content/uploads/`から直接参照している。WordPress廃止前に全資料を静的資産用の恒久パスへ移し、参照先を置換する。

- AJDC2026開催要項
- 誓約書
- 演技順
- 確定・暫定スケジュール
- 3月26日分・全競技結果
- AJDC2025結果

歴代結果ページには2012年以降の開催要項・結果・画像がさらにある。WordPress領域を削除する前に、参照されている全資産を一覧化してローカルへ保存し、静的資産の恒久URLへリンクを置換する。移行確認が完了するまで現行WordPressはバックアップ兼比較元として保全し、公開切替後に撤去する。

### 4. 協賛ロゴの掲出条件を確認する

旧サイトは12社・団体のロゴを表示し、新案は名称チップのみ表示している。契約・合意上ロゴ掲出が必要か、名称のみでよいかを協賛担当へ確認する。ロゴが必要なら、現行WordPressから取得するだけでなく、利用許可、最新版、背景色別データ、リンク先を確認してローカル管理する。

### 5. 本番切替とロールバックを準備する

- 現行AJDCのファイルとWordPressデータベースを同時にバックアップする。
- ロリポップの公開フォルダ、空き容量、FTPS権限、バックアップ機能を確認する。
- 本番とは別の候補フォルダで、実際のURL構造に近い状態を確認する。
- 切替対象を明文化し、OIDC/TIDCや協会本体を同時に上書きしない。
- 旧公開フォルダへ戻す手順と担当者を決める。
- 独自ドメイン設定を解除しない。

## 重要な次段階（P1）

### コンテンツと運用

- 年度、回数、開催日、会場、登録期間、状態、更新履歴、資料リンクを1つの更新データから生成できる構成にする。
- 「開催前」「登録中」「登録終了」「大会終了」の状態ごとにCTAを切り替える。
- 次年度更新時に、前年情報を歴代結果へ移す手順を決める。
- AJDC専用問い合わせの入力項目・送信先・自動返信を確認し、静的サイトで動作するフォームへ移行する。協会本体フォームへ統合する場合もAJDC用の問い合わせ種別と旧URL互換を維持する。
- 協会本体のサイト内検索・更新情報から、最終的なAJDC公開URLへつなぐ。

### コード保守

- インラインCSSに旧デザインと新デザインの上書きが二重に残っている。表示確定後、使われていない`.ajdc-brand`、`.ajdc-hero-card`、`.ajdc-facts`等を含めて単一のルールへ整理する。
- AJDC専用CSSを外部ファイル化する場合は、キャッシュ番号と更新手順をAJDC向けガイドへ記載する。
- 更新情報と資料一覧をHTML直書きのままにするか、JSON等から生成するかを決める。
- 外部リンク、PDF、フラグメント、重複IDを自動検査する公開前スクリプトを用意する。

### 表示・アクセシビリティ・SEO

- 完成画像でLCP、表示容量、モバイルの文字可読性を再計測する。
- 本文はシステムフォント構成へ整理済み。Windows/macOS/iOS/Androidで最終的な字幅と折返しを確認する。
- 現在は協会本体のエンブレムをfavicon／Apple Touch Iconとして暫定使用している。AJDC専用アイコン、OGP/Twitter Card、完成画像を用意する。
- 大会年度を含むtitle/descriptionとEvent構造化データを、毎年更新できる形にする。
- PDF・新規タブで開くリンクへ、見える注記またはアクセシブルな補足を付ける。
- 更新一覧と協賛一覧を`ul`/`li`等へ整理し、無名の`article`ランドマークを減らす。
- CSP、Referrer-Policy、Permissions-Policy等は本番HTTPヘッダーで設定する。厳格なCSPを使う場合はインラインCSSを外部化する。
