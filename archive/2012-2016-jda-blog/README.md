# 日本ディアボロ協会 公式ブログ アーカイブ 2012–2016

**読むための入口は [`index.html`](index.html)。** ブラウザで直接開ける。

## これは何か

2012年12月から2016年6月まで運用されていた協会公式ブログの記事を、SQLダンプから抽出して
HTMLに再構成したもの。**この内容が読める形で残っているのは、現時点でここだけ。**

2026-09-06 に確認した保全状況:

| 確認先 | 結果 |
|---|---|
| 旧サイト保全（50,380ファイル）に静的HTMLとして | 1件も無し |
| ローカルの `Weblog/` `blog/` フォルダ | 存在しない |
| 本番 `https://www.diabolo.jp/Weblog/` | 404 |
| データベース `wp1_posts` / `wp2_posts` | **記事あり（唯一の保管場所）** |

サーバー上のブログ用ファイルは過去に削除されているが、テーブルだけが残された状態で
8年以上経っていた。その状態から救い出したのがこのアーカイブ。

## 2つのブログの関係

| テーブル接頭辞 | URL | ブログ名 | 期間 |
|---|---|---|---|
| `wp1_` | `http://diabolo.jp/JDA_Weblog` | 日本ディアボロ協会公式ブログ | 2013年1月〜6月 |
| `wp2_` | `http://diabolo.jp/Weblog` | 日本ディアボロ協会 - 公式ブログ | 2012年12月〜2016年6月 |

2013年7月8日の記事「ブログを移行しました」により `wp1_` から `wp2_` へ移行し、過去記事も
日付を保ったまま取り込まれている。移行時に本文が書き直された記事が4件あるため、
`index.html` では各記事内に旧版を折りたたみで併記した。

## 収録内容

- 公開状態（`publish`）の投稿・固定ページ **25件**（下書き・ゴミ箱・リビジョンは除外）
- 本文が参照していた画像 **4点**。元URLではすべて消失していたため Wayback Machine から復元し
  `images/` に保存、本文の参照先もローカルへ差し替えた
- `posts.json` … 機械可読の正本データ（本文は加工前のまま）

## 再生成

```
python3 scripts/build_blog_archive.py
```

入力は `backups/2026-09-06_wp5-drop/LAA0217648-test.sql`（Git非追跡・ローカルのみ）。
このダンプが無い環境では再生成できないので、**このフォルダ自体が保全の実体**にあたる。

## 注意点

- `wp2_users` に管理者権限のアカウント `wp.service.controller.LNook` /
  `wp.service.controller.AzORp` が2つある。メールアドレスが空、登録日時が `0000-00-00` で、
  通常の作成手順では生まれない。**このブログが第三者に侵入されていた可能性が高い（未確定）。**
  稼働中の `/AJDC/`（`wp4_`）・`/OIDC/`（`wp3_`）に同種のアカウントは無いことを確認済み。
- 記事本文の外部リンクは全件確認し、不審な宛先は含まれていなかった。
- 表示にあたり、実際に使われていたタグ（`a, b, div, em, img, span, strong, wbr`）だけを通し、
  `style` 属性は除いた。文字そのものは変更していない。
- **ローカル確認用。** `scripts/release_config.py` の公開対象に `archive/` は含まれておらず、
  本番サイトへは公開されない。
