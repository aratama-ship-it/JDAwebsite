# COMPETITION SCENES — portrait-first slideshow

`diabolo.jp` トップページへ大会実写スライダーを追加するための、ローカル専用比較案です。

- 本体の `index.html` / `css/style.css` / `js/main.js` は変更しません。
- ホームを読み込んだ時に大会写真をモーダルで自動表示します。
- 閉じた後はページ上部の「大会写真を見る」ボタンから再表示できます。
- 閉じるボタン・背景クリック・Escキーで閉じられ、開いている間は背景を操作できません。
- PCの横長画面では、連続する縦写真を2枚並べ、横写真は1枚で全面表示します。
- 矢印・自動送りは写真の向きから作られたページ単位で進みます。組にならない縦写真は中央に表示します。
- PCの縦長画面とスマホでは、大会写真を1枚ずつ大きく表示します。
- スマホの写真フレームは4:5に固定し、Photoshopで同じ比率の画像を用意すれば余白なく表示できます。
- デスクトップでは写真の元の縦横比を保ち、縦長・横長とも切らずに表示します。
- 同じ写真をぼかした背景で、縦写真の左右余白と横写真の混在を自然に処理します。
- 写真ごとのタイトルや大会名は表示せず、フォルダ内の写真がどの大会のものでも使える中立的なUIです。
- 6.5秒ごとの自動送りと、停止・矢印・キーボード・スワイプ操作に対応します。
- 写真を増やす時は `index.html` の `[data-scene]` を1件複製し、画像の実寸に合う `width` / `height` も設定します。PC表示ではこの値から縦横を判定します。

現在の5枚では、PC横長時に「縦2枚」→「横1枚」→「横1枚」→「横1枚」の4ページになります。スマホでは5ページです。

Photoshopテンプレートは **1600 × 2000 px（4:5）／sRGB** を推奨します。写真内に大会名やタイトルは焼き込まず、人物やディアボロが上下端に接しない配置にすると、端末差があっても主役を保ちやすくなります。
